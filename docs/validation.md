# 示例运行与核验记录

核验日期：2026-10-09。使用 R 4.4.3、当前审查后的 BLSD 核心、原微信示例模拟数据及 1,000 次系数抽样。没有在此示例中使用真实死亡监测资料。

- 模拟数据：seed 123 与 seed 42 均逐字段复现原示例生成公式及随机数调用顺序；默认数据有 540 个观测。
- 完整运行：生成 13 组图表，每组一张 PNG 和一份 PDF，以及 21 张 CSV 结果表。
- 系数抽样、曲面、导数与结果表：检查维度、同次抽样对应关系、均值和分位数区间。
- 百分比结果：检查先对每次导数抽样作 100 × expm1，再计算汇总；没有用变换后的均值替代逐抽样均值。
- 计数模型：检查人口偏置项、观察值与拟合值对应关系及相关残差。
- 动态指标：检查不等距年龄／时间间隔、区间标签、小年龄梯度筛选与有效比例。
- APC：20 列、秩 20；每次抽样的重建最大绝对误差约 1.24 × 10⁻¹⁴，按设计列范数归一的最大剩余交叉乘积约 1.74 × 10⁻¹²。
- 图表输出：检查 PNG／PDF 签名与成对文件、图表清单路径，以及主要多联图的排版。非等距年龄热图采用显式单元边界，避免出现空白带。

以下命令均已通过：

```sh
Rscript tests/test_wechat_example.R
Rscript tests/test_blsd_core.R
Rscript BLSD_Model_Analysis.R --draws=1000 --output=outputs/demo
Rscript tests/verify_demo_outputs.R outputs/demo
```

这些检查验证数据溯源、数值实现和输出一致性。它们不证明经验贝叶斯区间在所有数据情形下均已校准，也不证明本流程优于传统 APC、BAPC 或其他二维平滑方法。
