# 对照微信原版的修改说明

比较基准是用户提供的微信原版 `BLSD_Model_Analysis.R`，共 167 行，`set.seed(123)` 位于第 11 行。下表行号均指原版。

当前 [BLSD_Model_Analysis.R](../BLSD_Model_Analysis.R) 保留原版“环境准备—数据模拟—模型构建—可视化—输出展示”的顺序。只保留核心计算和七组绘图，图表直接在 RStudio 的 Plots 面板显示。当前分析不使用命令行参数、通用对象框架、自动图片／表格导出或独立检查脚本。

## 核心修改

| 注释编号 | 原版位置 | 当前修改与原因 |
|---|---|---|
| M01 | 第 4–9 行 | 依赖精简为 `mgcv`、`ggplot2`、`gridExtra`，使用直接绘图所需功能 |
| M02 | 第 11、18–53 行 | 保留种子 123、540 个观测和原模拟式，保持同一数据基准 |
| M03 | 第 66–68 行 | 准 Poisson 改为负二项，显式 REML；保留张量积和人口偏置项 |
| M04 | 第 82–83 行及原版点估计流程 | 新增 1,000 次相关系数抽样，传播率和指标的不确定性 |
| M05 | 第 77–83 行 | 在观测范围内构建网格，人口取 1，从预测矩阵取得对数率，避免超出最高代表年龄外推 |
| M06 | 第 87–96 行 | 同点有限差分分别计算时间一、二阶导数，修正展开向量直接做差和时间单位问题 |
| M07 | 原版无年龄导数 | 新增同点年龄导数，用于横断面年龄变化与移动速度 |
| M09 | 第 92、116–118 行 | 年度与年龄导数逐抽样换算为局部相对变化百分比，便于读图 |
| M10 | 第 99–108 行仅有等高线 | 新增 `-时间导数/年龄导数`，小分母抽样设为缺失；量化等死亡率位置移动 |
| M11 | 第 129–139 行 | 保留队列计数残差图，收紧说明，避免将残差平滑误解为队列效应 |
| M12 | 第 146–150 行 | 精确提取 1990、2005、2019 年，并叠加观测率和区间，避免邻年混入 |
| M13 | 原版无指定年龄区间趋势图 | 新增选定年龄的趋势、观测值及逐点区间，直接比较时间变化 |

编号沿用前一版本的核心修改标记。原 M08 所属区间差分流程和 M14 所属通用检查框架已移除，仅保留一套导数算法；这两个编号不再出现在本版源码中。

原版第二张图虽然部分注释称“加速度”，实际绘制的是一阶时间导数。原版 `c(NA, diff(pred_grid$Deriv_Time))` 不具备完整的二阶导数时间尺度，还可能在年龄分组交界处相减；本版明确分开速度和加速度。

百分比换算是显示尺度改进，使用每次抽样的 `100 * expm1(导数)` 后再汇总。等死亡率移动是新增衍生指标，单位为岁／年；相对于基准年的等效年龄值仍未实现。负二项、REML 和高斯系数抽样采用已有方法，不能仅据此声称统计理论首创或预测优越性。

详细公式与参考文献见 [方法说明](methods.md)。
