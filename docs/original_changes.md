# 对照微信原版的修改说明

比较基准为用户提供的微信原版 `BLSD_Model_Analysis.R`，共 167 行，第一行为分隔注释，`set.seed(123)` 位于第 11 行。下文行号均指这个原版，不是修改后的行号。当前版本在同名根脚本中保留原数据生成机制，修改模型和绘图代码，以 BLSD-S 曲面和动态指标为主体，生成九组图表。

修改后的 [BLSD_Model_Analysis.R](../BLSD_Model_Analysis.R) 是完整分析脚本，数据、模型、九组图表和输出代码均在其中。`[修改 M01]` 至 `[修改 M14]` 注释放在对应实现附近，标明原版位置、当前调整及其意义。

文件保留原版五个大段的组织顺序，并将较长计算整理为同文件内的函数：第 0 段准备依赖与运行参数，第 1 段定义 `simulate_wechat_example()`，第 2 段定义拟合、抽样和预测，第 3 段定义导数与 `make_blsd_demo_figures()` 的全部九图，第 4 段的 `run_blsd_demo()` 执行流程并保存。运行根脚本即可生成数据和结果；无需其他分析文件或已有 CSV。函数封装用于明确年龄轴、抽样及重复绘图的处理，不改变原例的随机数生成顺序。

## 三处容易误读的修改

**M06 是计算纠错。** 原版第 96 行 `c(NA, diff(pred_grid$Deriv_Time))` 对展开向量做差，没有除以时间间隔，年龄分组交界处可能跨年龄相减。当前按二维结构计算。原版第 112 行称“加速度场”，第 116 行却绘制一阶时间导数；当前图 02 和图 03 分别展示速度的百分比和对数率加速度。

**M08 与 M10 属于不同层次。** 原版只有等高线，M10 新增移动速度。M08 修正后续模块的离散时间对齐，以区间两端年龄梯度均值作分母。不能给原版虚构一个已经存在的移动速度公式。

**M09 改变显示尺度。** 年龄梯度 0.10 换算为约 10.5% 的局部一岁相对变化，必须逐抽样换算。对均值先取指数通常不能得到该百分比的抽样均值；区间应由对应抽样分布计算。这也不是精确有限年龄对比。
