# BLSD Tool

[English](README.md) | [简体中文](README.zh-CN.md)

**BLSD Tool** 是 **BLSD（Bayesian Lexis Surface Dynamics）** 模型的网页界面，用于估计和分析平滑的年龄—时期率曲面。它结合了 React 界面、ECharts 交互图表和使用 `mgcv` 的 R 后端。界面提供英文和中文版本。

本目录包含应用的源代码，发布于 [Aprilxxi/BLSD 仓库](../README.zh-CN.md)的 `web/` 目录。

**公开网页地址：** 待补充。

## 环境要求

- Node.js **22.12.0 或更高版本**。
- Corepack，以及 `package.json` 指定的 **pnpm 11.25.0**。
- R，以及 `mgcv`、`jsonlite`、`ggplot2` 和 `scales` 包。
- R 需支持所使用的图表导出格式。PDF 和 TIFF 导出需要相应的图形功能；中文图表标签还需要服务器安装合适的字体。

在 R 会话中安装所需包：

```r
install.packages(c("mgcv", "jsonlite", "ggplot2", "scales"),
                 repos = "https://cloud.r-project.org")
```

后端使用 `PATH` 中的 `Rscript` 可执行文件。如需指定某个 R 安装版本，请将 **`BLSD_RSCRIPT`** 环境变量设置为该可执行文件的位置。服务器还会检查 Windows 上常见的 R 安装位置。

## 本地运行

从仓库根目录执行：

```sh
cd web
corepack pnpm install --frozen-lockfile
corepack pnpm dev --host 127.0.0.1 --port 4175
```

打开 <http://127.0.0.1:4175>。开发服务器包含分析 API，并调用 R 拟合模型。加载固定示例或提供 CSV，选择分析设置，然后点击**运行分析**。

构建并运行生产应用：

```sh
corepack pnpm build
node deployment/check-environment.mjs
corepack pnpm start
```

生产构建将浏览器资源写入 `dist/client/`。使用 `node server/index.mjs`（或 `corepack pnpm start`）启动 Node/R 应用，默认监听 <http://127.0.0.1:4174>。设置 `PORT` 可更改端口。

环境检查应在构建完成后运行。可使用 `corepack pnpm test` 运行测试套件；依赖 R 的集成检查需要可用的 R 安装。

## 输入数据

上传、拖放或粘贴包含以下列的 UTF-8 CSV：

| 列名 | 含义 |
| --- | --- |
| `Year` | 数值型日历年份或时期坐标。 |
| `Age_Group` | 两端封闭的整数年龄区间，例如 `30-34` 或 `30-34 years`。 |
| `Count` | 非负事件计数；接受非整数估计值。 |
| `Pop` | 与计数对应的正数人口或暴露量分母。 |
| `Sex` | 可选的非空分组标签；各组分别拟合。 |

列的顺序可以不同。每个分组—年龄—时期组合必须唯一。年龄组必须是互不重叠的封闭区间。例如，`30-34` 的年龄坐标为 32.5，计算方式为 `(lower + upper + 1) / 2`。每个拟合组至少需要五个不同的年龄坐标和五个不同的时期坐标，并且观测数应足以支持所选基函数维数。上传大小上限为 5 MiB。

### 固定示例与随机种子

随附的[示例 CSV](data/example/example_data.csv) 包含 442 条合成观测：13 个五岁年龄组，从 30–34 岁至 90–94 岁，观测年份为 1990–2023 年。数据使用**数据生成种子 `20261022`** 一次性生成，每次加载时保持不变。生成规则记录在[固定的数据生成配置](data/example/dgp_fixed_before_sampling.json)中。

另一个独立的**系数抽样种子默认为 `123`**，可在高级分析设置中更改。更改该设置会改变用于不确定性汇总的模拟系数抽样，但不会重新生成示例观测。

## 模型与界面默认设置

模型使用对数连接函数、年份和年龄上的自然三次回归样条张量积，以及对数暴露量偏置项：

```r
Count ~ te(Year, Age_Mid, bs = c("cr", "cr")) + offset(log(Pop))
```

**网页界面的默认设置**如下：

| 设置 | 默认值 |
| --- | --- |
| 分布族与平滑参数选择 | 负二项分布，使用 REML |
| 边际基函数维数 | 年龄为 10，年份为 10；根据可用坐标的需要降低 |
| 联合系数抽样次数 | 1,000 |
| 系数抽样种子 | 123 |
| 等效年龄移动的年龄梯度阈值 | 0.005 |

也可选择使用 REML 或 GCV 的准泊松模型。不确定性汇总使用近似贝叶斯系数抽样。显示的 95% 不确定区间是拟合模型的逐点区间。率以每 100,000 个分母单位表示。

## 结果与下载

每个成功拟合的组提供八种视图：

1. 拟合率或对数率曲面。
2. 局部年度百分比变化。
3. 对数率在时间方向上的曲率，显示于加速度视图。
4. 所选时期的年龄剖面。
5. 年龄别时间趋势。
6. 年龄梯度。
7. 等效年龄移动。
8. 偏差残差。

下载内容包括覆盖每个成功拟合组全部八种视图的**图表归档**、每组包含一个工作簿的**数据表归档**，以及**完整分析归档**。图表可导出为矢量 PDF 或 600 dpi PNG/TIFF。数据表包含输入、估计值、不确定性汇总和诊断结果。完整归档还包括标准化输入数据、完整结果 JSON、保存的 R 模型、系数抽样和分析设置。这些导出使用保留的拟合结果和抽样，不重新拟合模型。

## 部署与数据保留

分析需要 Node/R 服务。Linux 部署请参阅[Linux 部署指南](deployment/DEPLOYMENT_LINUX_zh.txt)（中文）和 [`deployment/`](deployment/) 中的配置示例，其中包括运行环境检查、服务设置、反向代理和 HTTPS 配置。

安装依赖并构建应用后，可使用 Python 3.9 或更高版本生成仅包含运行所需文件的 Linux 归档：

```sh
python scripts/package-release.py --linux
```

命令会报告位于 `../output/deployment/` 下的归档位置。请使用生成的归档及其校验和，替代部署指南中带日期的示例文件名。每个新归档都包含项目的 MIT 许可证和第三方声明。

服务默认保留**最近五次分析运行**，每次运行的**保留时长为一小时**，从完成时开始计算。包含多个性别组的运行计为一次分析。输入和生成的文件临时存放在服务器任务目录中；到期和正常关闭时会清理应用保留的文件。重启服务会使保留的结果失效，因此请在结果可用期间下载所需归档。

部署时应配置服务器日志、反向代理日志、备份及其保留策略。应用的清理机制不管理单独维护的日志或备份。当前服务没有内置账户或按用户隔离结果的功能；部署访问控制应与预期使用人群相匹配。
