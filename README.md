# BLSD：死亡率曲面、动态指标与 APC 分解示例

本仓库提供可直接运行的 R 示例：从模拟死亡数与人口开始，估计年龄—时期死亡率曲面，计算动态指标，再将曲面分解为受约束的年龄、时期、队列（APC）贡献及剩余面。运行后生成 13 组图表，每组同时保存 PNG 和 PDF，并输出结果表供复核。

示例数据复现原微信示例脚本的模拟流程，采用 `set.seed(123)`、1990—2019 年和 18 个年龄组。仓库中的 `data/wechat_example.csv` 是模拟数据；本仓库未包含真实监测数据。默认使用负二项模型拟合，但原示例的死亡数由 Poisson 分布生成。这两件事分别是分析模型与数据生成机制，不能混称。

## 快速运行

安装 R，在仓库根目录执行：

```sh
Rscript install_dependencies.R
Rscript BLSD_Model_Analysis.R
```

依赖为 `mgcv`、`ggplot2` 和 `gridExtra`。如果系统无法识别 `Rscript`，可在 R 或 RStudio 中将工作目录设为本仓库，先执行：

```r
source("install_dependencies.R")
source("BLSD_Model_Analysis.R")
```

默认输出目录为 `outputs/demo`，系数抽样次数为 1,000。先查看图表是否正常生成，可使用：

```sh
Rscript BLSD_Model_Analysis.R --draws=300 --output=outputs/demo_smoke
```

正式展示需要检查区间与抽样次数的稳定性，不能把快速运行直接当作方法性能验证。查看可用选项：

```sh
Rscript BLSD_Model_Analysis.R --help
```

## 图表内容

| 图 | 内容 | 主要回答的问题 |
|---|---|---|
| 01 | 死亡率曲面与等死亡率线 | 哪些年龄、年份的死亡率较高？相同死亡率的位置如何变化？ |
| 02 | 局部年度死亡率相对变化（%） | 固定年龄的死亡率上升或下降多快？ |
| 03 | 对数死亡率加速度 | 变化速度是在增加还是减少？ |
| 04 | 偏差残差与出生队列 | 按出生队列观察时，拟合后还剩哪些计数残差结构？ |
| 05 | 1990、2005、2019 年年龄截面 | 不同年份的年龄—死亡率关系有什么差异？ |
| 06 | 选定年龄的时间趋势、观测值与区间 | 各年龄的趋势和不确定性如何？ |
| 07 | 局部年龄相对变化（%）与等死亡率年龄移动速度 | 同年年龄差异有多陡？同一死亡率每年移动多少岁？ |
| 08 | 年龄梯度与年龄移动速度的区间方向分类 | 哪些位置的逐点区间排除了零？ |
| 09 | 观测／拟合死亡数与偏差残差 | 计数拟合在哪些位置偏离较大？ |
| 10 | APC 贡献曲线 | 在选定约束下，年龄、净漂移、时期和队列贡献是什么形状？ |
| 11 | 六个分解分量的热图 | 各分量如何分布于年龄—时期网格？ |
| 12 | 完整曲面、APC 部分与剩余面 | 当前 APC 表示概括了多少曲面结构？ |
| 13 | 剩余面对应的死亡率倍数 | 完整死亡率相对于 APC 部分高或低多少？ |

图 02 和图 07 的百分比先在每次抽样中换算，再汇总。年龄梯度使用 `100 * expm1(g)`，其中 `g` 为对数死亡率对年龄的导数；这是将局部斜率延伸一岁得到的近似，便于阅读。严格的相邻年龄差异需要直接比较曲面上两个年龄的死亡率。

等死亡率年龄移动速度的单位是“年龄岁／日历年”。它表示同一死亡率水平的位置变化，并非相对于基准年的绝对等效年龄，也不是个人生理年龄或寿命的变化。年龄梯度接近零时，该比值不稳定；图中会标记保留抽样比例较低的位置。

图中区间均为逐点的近似系数不确定性区间。颜色表示估计值时，红色或蓝色本身不能证明方向确定。图 08 的分类也不是对整张图进行了多重比较校正。

## 分析流程与文件

```text
模拟死亡数 + 匹配人口
       │
       ▼
BLSD-S：负二项张量积平滑曲面，REML 选择平滑程度
       │
       ▼
同一组相关系数抽样 → 死亡率、导数、百分比与年龄移动速度
       │
       ▼
BLSD-APC：逐抽样的受约束等权投影 → APC 分量 + 剩余面
```

| 路径 | 用途 |
|---|---|
| `BLSD_Model_Analysis.R` | 一键运行入口 |
| `install_dependencies.R` | 安装所需 R 包 |
| `R/blsd_models.R` | 曲面拟合、抽样、动态指标与 APC 分解的核心实现 |
| `data/wechat_example.csv` | 原模拟流程的示例数据 |
| `docs/methods.md` | 数据生成式、模型式、指标、约束与参考文献 |
| `examples/` | 全部 13 组 PNG／PDF 示例图表 |
| `tests/` | 核心数值检查 |
| `outputs/demo/figures/` | 本次运行产生的 PNG／PDF |
| `outputs/demo/tables/` | 图表清单及结果表 |

完整抽样对象保存在运行输出中，便于追溯结果。`outputs/` 被版本控制忽略，仓库保留源代码、模拟 CSV 与示例图表，避免上传大量运行对象。

运行后可核对示例数据与数值结果：

```sh
Rscript tests/test_wechat_example.R
Rscript tests/test_blsd_core.R
Rscript tests/verify_demo_outputs.R outputs/demo
```

## 与原示例的主要区别

| 原示例 | 当前实现 |
|---|---|
| 准 Poisson 曲面 | 默认负二项曲面，显式使用 REML |
| 主要展示点估计 | 将相关系数抽样传播至死亡率、导数、比值和 APC 分量 |
| 展开后的导数向量直接做差 | 按年龄和时间计算差分；另提供同一点的连续导数近似 |
| 未单独量化年龄梯度 | 新图按每次抽样换算为局部相对变化百分比 |
| 等死亡率线的视觉描述 | 新增年龄移动速度及其区间与有效抽样比例 |
| 残差按队列作图 | 保留为计数诊断，并新增正式的受约束 APC 曲面分解 |

上述调整包含计算纠错、结果量化和解释层扩展。负二项、REML、样条和高斯系数抽样均有既有方法基础；本示例不据此声称统计理论首创或预测优越性。

## 使用边界

- `85+` 组取 90 岁仅为复现原示例的演示假设；真实开放年龄组需要另行确定代表年龄或使用合适的分组模型。
- 预测范围限于示例的年龄和年份范围。密集绘图网格是插值位置，不是新增观测。
- 当前抽样属于经验贝叶斯的高斯近似，没有对全部平滑参数与离散参数进行联合后验抽样。
- APC 是拟合曲面的结构摘要，没有重新拟合死亡计数；约束不消除原始 APC 的不可识别问题，分量不具有自动的因果含义。
- 加回剩余面后能恢复完整曲面是代数恒等式，不能当作模型性能证据。

详细数学定义、剩余面的解释及参考文献见 [方法说明](docs/methods.md)。
